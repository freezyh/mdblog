## 一、支付模块（大纲第 6 部分）

## 1. 支付宝支付（Flutter 支付宝支付）

**用法**：流程为「App 后端下单 → 后端调支付宝接口生成签名参数 → App 拿参数唤起支付宝 SDK → 支付宝异步回调后端」。Flutter 侧一般用插件（如 `tobias`）或 MethodChannel 接原生 SDK。

```
申请准备：
1. 注册支付宝开放平台企业账号 → 创建应用
2. 配置应用网关、异步通知地址、加签密钥（RSA2）
3. 申请"APP支付"产品权限
```

```dart
// Dart 侧（tobias 插件示意）
import 'package:tobias/tobias.dart';

Future<void> payWithAlipay(String orderInfo) async {
  // orderInfo 由后端返回（含签名），SDK 只负责唤起与验签
  var result = await pay(orderInfo);
  print(result['resultStatus']);    // 9000 成功，6001 用户取消
  if (result['resultStatus'] == '9000') {
    // 提示支付成功（最终以服务端异步通知为准）
    refreshOrderStatus();
  }
}
```

> 注意：客户端回调只能做"展示"，真实成功与否以服务端 `notify_url` 异步通知为准。

## 2. 微信支付（Flutter 微信支付，iOS/Android）

**用法**：后端统一下单拿 `prepay_id` → 组装 SDK 参数 → `fluwx` 唤起微信 → 在微信回调里处理结果。

```dart
// fluwx 示意
await registerWxApi(appId: 'wx1234567890', universalLink: 'https://yourdomain/app/');

Future<void> payWithWechat(Map payParams) async {
  // payParams 由后端返回：partnerId/prepayId/nonceStr/timeStamp/sign/package
  final result = await fluwx.pay(WeChatPayModel(
    appId: payParams['appid'],
    partnerId: payParams['partnerid'],
    prepayId: payParams['prepayid'],
    packageValue: payParams['package'],
    nonceStr: payParams['noncestr'],
    timeStamp: payParams['timestamp'],
    sign: payParams['sign'],
  ));
  if (result.isSuccessful) refreshOrderStatus();
}
```

> iOS 端需在微信开放平台配置 **universalLink**；Android 需配置应用签名。商户号（MchID）申请、API 证书由后端使用。

## 3. Flutter provider 状态管理

**用法**：官方推荐的状态管理，`ChangeNotifier` + `Consumer`/`context.watch`。

```yaml
dependencies: { provider: ^6.1.1 }
```

```dart
class UserProvider extends ChangeNotifier {
  String? nickname;
  bool get isLogin => nickname != null;

  void setUser(String name) { nickname = name; notifyListeners(); }
  void logout() { nickname = null; notifyListeners(); }
}

// 多个 provider 组合注册（购物车 + 用户）
MultiProvider(
  providers: [
    ChangeNotifierProvider(create: (_) => CartProvider()),
    ChangeNotifierProvider(create: (_) => UserProvider()),
  ],
  child: const App(),
)

// 页面读取/监听
final user = context.watch<UserProvider>();
context.read<UserProvider>().setUser('张三');   // 事件里用 read
```

## 4. go_router（声明式路由）

**用法**：官方推荐的路由库，支持路径参数、重定向（登录守卫）、嵌套路由。

```yaml
dependencies: { go_router: ^12.1.0 }
```

```dart
final router = GoRouter(
  initialLocation: '/',
  routes: [
    GoRoute(path: '/', builder: (c, s) => const HomePage()),
    // 路径参数：/goods/1001
    GoRoute(path: '/goods/:id', builder: (c, s) => GoodsPage(id: s.pathParameters['id']!)),
    // 查询参数：/search?kw=手机
    GoRoute(path: '/search', builder: (c, s) => SearchPage(kw: s.uri.queryParameters['kw'])),
  ],
  // 登录守卫：未登录强制跳登录页
  redirect: (context, state) {
    final loggedIn = Global.userProvider.isLogin;
    if (!loggedIn && state.matchedLocation != '/login') return '/login';
    return null;
  },
);

MaterialApp.router(routerConfig: router);

// 使用
context.push('/goods/1001');
context.push('/search?kw=手机');
context.go('/');                  // 替换（清栈）
context.pop();
```

## 5. Flutter Realm 本地数据库

**用法**：比 sqflite 更好用的移动端数据库（面向对象、自动响应）。

```yaml
dependencies: { realm: ^2.3.0 }
```

```dart
import 'package:realm/realm.dart';

// 1) 定义模型
@RealmModel()
class _ChatMsg {
  @PrimaryKey()
  late ObjectId id;
  late String content;
  late int sendTime;
  late bool fromMe;
}

// 2) 初始化并读写
var config = Configuration.local([ChatMsg.schema]);
var realm = Realm(config);

// 增
realm.write(() => realm.add(ChatMsg(
  ObjectId(),
  content: '你好',
  sendTime: DateTime.now().millisecondsSinceEpoch,
  fromMe: true,
)));

// 查（排序、过滤）
var msgs = realm.query<ChatMsg>('content CONTAINS "你" SORT(sendTime DESC)');

// 删
realm.write(() => realm.delete(msgs[0]));
```

## 7. 百度地图：显示地图、添加/删除标记、添加/删除文字（Flutter 百度地图）

```yaml
dependencies:
  flutter_baidu_mapapi_map: ^3.9.0
  flutter_baidu_mapapi_search: ^3.9.0
```

```dart
import 'package:flutter_baidu_mapapi_map/flutter_baidu_mapapi_map.dart';

class MapPage extends StatefulWidget {
  const MapPage({super.key});

  @override
  State<MapPage> createState() => _MapPageState();
}

class _MapPageState extends State<MapPage> {
  BMFMapController? _controller;
  List<BMFMarker> markers = [];

  @override
  Widget build(BuildContext context) {
    return BMFMapWidget(
      onBMFMapCreated: (controller) {
        _controller = controller;
        addMarker();
      },
      mapOptions: BMFMapOptions(
        center: BMFCoordinate(22.54, 114.05),   // 深圳
        zoomLevel: 14,
      ),
    );
  }

  // 添加标记（充电桩场景：显示桩位）
  void addMarker() {
    var marker = BMFMarker(
      position: BMFCoordinate(22.54, 114.05),
      icon: 'assets/images/station.png',
      identifier: 'station_001',
    );
    markers.add(marker);
    _controller?.addMarker(marker);

    // 点击标记回调
    marker.onTap = () => showStationDetail('station_001');
  }

  // 删除标记
  void removeMarkers() {
    _controller?.removeMarkers(markers);
    markers.clear();
  }

  // 添加文字标注
  void addText() {
    var text = BMFText(
      position: BMFCoordinate(22.54, 114.05),
      text: '充电站(有8个空位)',
      color: Colors.blue,
      fontSize: 14,
    );
    _controller?.addText(text);
  }

  // 删除文字
  void removeText(BMFText text) => _controller?.removeText(text);
}
```

## 8. 充电桩项目实战（架构概述）

**用法**：典型「地图 + 扫码 + IoT 状态 + 支付」组合项目，串联了本教程大部分知识点。

```
核心流程：
1. 首页百度地图 → 显示附近充电桩标记（接口 + addMarker）
2. 点击标记 → 桩位详情（空闲/占用，轮询或 MQTT 更新状态）
3. 扫码（mobile_scanner）→ 绑定枪号
4. 启动充电（服务端下发 MQTT 指令，App 监听状态变化）
5. 充电中：实时电量/金额（StreamBuilder / MQTT 消息流）
6. 结束充电 → 计算金额 → 微信/支付宝支付（见本章支付部分）
7. 订单列表、发票、用户中心（shared_preferences 存 token）
```

技术栈：go_router / provider（或 GetX）+ dio + 百度地图 + MQTT + 支付插件 + Realm（离线缓存订单）。

```dart
// 扫描设备
FlutterBluePlus.startScan(timeout: const Duration(seconds: 5));
FlutterBluePlus.scanResults.listen((results) {
  for (var r in results) {
    print('${r.device.name} ${r.rssi}');
    if (r.device.name == 'MY-DEVICE') {
      FlutterBluePlus.stopScan();
      connect(r.device);
    }
  }
});

// 连接 + 订阅特征值（手环/硬件数据上报）
Future<void> connect(BluetoothDevice device) async {
  await device.connect();
  var services = await device.discoverServices();
  for (var s in services) {
    for (var c in s.characteristics) {
      if (c.properties.notify) {
        await c.setNotifyValue(true);
        c.value.listen((data) => print('收到硬件数据: $data'));  // Uint8List 解析
      }
    }
  }
}
```

## 11. 操作 WiFi 模块 / 集成 MQTT 无线控制（mqtt_client）

**用法**：IoT 项目标配。硬件模块作为 MQTT 客户端订阅主题，App 发布指令 / 订阅状态。

```yaml
dependencies: { mqtt_client: ^10.2.0 }
```

```dart
import 'package:mqtt_client/mqtt_client.dart';
import 'package:mqtt_client/mqtt_server_client.dart';

final client = MqttServerClient('broker.emqx.io', 'flutter_app_001')
  ..port = 1883
  ..keepAlivePeriod = 30;

await client.connect();

// 订阅设备状态
client.subscribe('charger/001/status', MqttQos.atLeastOnce);
client.updates!.listen((List<MqttReceivedMessage> messages) {
  final msg = messages[0].payload as MqttPublishMessage;
  var payload = MqttPublishPayload.bytesToStringAsString(msg.payload.byteBuffer!);
  print('设备状态: $payload');     // {"state":"charging","power":32.5}
});

// 发布控制指令（开关充电）
void sendCommand(String cmd) {
  final builder = MqttClientPayloadBuilder();
  builder.addString('{"cmd":"$cmd"}');
  client.publishMessage('charger/001/cmd', MqttQos.atLeastOnce, builder.payload!);
}

sendCommand('start');
sendCommand('stop');
```

> App 侧把 MQTT 消息流包成 `Stream`，用 `StreamBuilder` 驱动充电页 UI 刷新。

## 13. Flutter 流 Stream（进阶）

```dart
import 'dart:async';

class ChargerBloc {
  final _controller = StreamController<double>.broadcast();   // broadcast 可多页面订阅
  Stream<double> get powerStream => _controller.stream;

  // 模拟硬件每秒上报功率
  void simulate() {
    Timer.periodic(const Duration(seconds: 1), (t) {
      _controller.sink.add(30 + t.tick * 0.5);
    });
  }

  void dispose() => _controller.close();
}

// UI：StreamBuilder
StreamBuilder<double>(
  stream: bloc.powerStream,
  builder: (context, snapshot) {
    return Text('当前功率: ${snapshot.data ?? 0} kW');
  },
)
```
